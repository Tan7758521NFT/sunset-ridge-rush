# Sunset Ridge Rush

An original pseudo-3D sunset racing game built for the make.fun "Make the best game" bounty (best-game-01).

3 laps around a sunset ridge circuit against 5 AI rivals and 7 traffic cars, with nitro boost, checkpoints, a HUD, and fully synthesized WebAudio sound. No external assets, no network requests.

Play: open `game/index.html` in desktop Chrome. Arrow keys / WASD to drive, Shift for nitro, P to pause, M to mute, R to restart.
